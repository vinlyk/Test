## TradingView MCP Constraints

TradingView Basic/Free plan limits charts to 2-3 indicators. When setting up charts, prioritize indicators by importance and warn about limits before attempting to add more than 3. Suggest combining or sequencing indicators if possible.

## MCP Workflow

When using MCP tools, always run a health check first (e.g., `tv_health_check`) to confirm the server is connected before attempting other operations.

After adding or configuring a new MCP server, remind the user they may need to restart the Claude session before the tools become available.
